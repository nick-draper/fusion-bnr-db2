Getting a figure into the README

Adaptive export embeds both palettes and switches on the reader's colour scheme through prefers-color-scheme, which GitHub honours for SVGs shown with ![alt](docs/images/…svg). Light and Dark export one palette only.

GitHub draws README images without web fonts. The SVG names the chosen family first and falls back to the system stack (San Francisco, Segoe UI, Helvetica, Arial; Menlo or Consolas for data), so line lengths in each drawing leave room for a slightly wider fallback.

Replace the file of the same name in docs/images/; the README references stay as they are.
